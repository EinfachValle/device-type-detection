Features

Zero Dependencies

Framework-agnostic with zero runtime dependencies. Works with React, Vue, Svelte, or vanilla JS.

Smart Detection

Combines User Agent, viewport width, and touch capability for accurate device classification.

Real-time Updates

ResizeObserver, resize events, and orientation changes — all throttled and deduplicated.

SSR Support

Server-side rendering with configurable device-type defaults. No window object required.

Orientation Aware

Detects portrait and landscape with combined flags like isMobileVertical and isTabletHorizontal.

Custom Breakpoints

8 fully configurable thresholds from 380px to 3840px. Covers mobile_s through tv_4k.

Quick Start

import { createDeviceDetector } from 'device-type-detection'; const detector = createDeviceDetector(); detector.subscribe((state) => { console.log(state.deviceType); // "mobile_m" console.log(state.isMobile); // true console.log(state.orientation); // "portrait" });
